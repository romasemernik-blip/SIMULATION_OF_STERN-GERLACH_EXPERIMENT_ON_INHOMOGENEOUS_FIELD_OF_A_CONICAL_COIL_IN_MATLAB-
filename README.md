# SIMULATION_OF_STERN-GERLACH_EXPERIMENT_ON_INHOMOGENEOUS_FIELD_OF_A_CONICAL_COIL_IN_MATLAB-
A MATLAB simulation of the Stern-Gerlach experiment using a conical solenoid. The code calculates the coil's axial magnetic field, models the quantum spin states of a silver atomic beam, integrates 3D particle trajectories, and visualizes the spatial splitting of the beam on three virtual detectors.
MATLAB Simulation of the Stern-Gerlach Experiment with a Conical Solenoid
Overview
This repository contains a MATLAB simulation of the historic Stern-Gerlach experiment. The code models the classical/quantum trajectory of silver atoms as they pass through a non-uniform magnetic field generated by a conical solenoid. It demonstrates the spatial quantization of the magnetic moment (spin) by modeling the splitting of the atomic beam into two distinct branches and their subsequent registration on virtual detectors.

📖 Overview
This repository contains a complete numerical simulation of the historic Stern-Gerlach experiment, modernized with a conical solenoid magnetic field geometry. The code bridges classical mechanics and quantum physics by modeling the generation of the magnetic field, the quantum discretization of the atomic magnetic moments, the 3D flight trajectories of the particles, and their final spatial distribution on virtual detectors.
